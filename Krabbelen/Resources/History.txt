Version history of the Krabbelen application.
=============================================
Version 1.0.4.8 (2026-08-01)
* Added a new feature to show the keywords in a larger font size when hovering over a krabbel in the KeywordCard (Animation).

Version 1.0.3.7 (2026-07-23)
* Bug fix: Copied Keywords.Clear() back. New keywords was not directly visible.

Version 1.0.3.6 (2026-07-16)
* Added Escape key handling to close the KrabbelWindow when pressed. This allows users to quickly exit the window without needing to click the close button.
* Bug fix: Keywords.Clear() was replaced with a new ObservableCollection to avoid issues with the UI.
  It looked like that Keywords.Clear() causes unexpected errors.

Version 1.0.3.5 (2026-07-14)
* Bug fix: Double-clicking on a krabbel in the DataGrid now correctly opens the selected krabbel, even when a selected saved.

Version 1.0.3.4 (2026-07-05)
* Added window to show the version history of the application. The history.txt file is now displayed in a read-only TextBox within the application, allowing users to easily view the version history without needing to open the file externally. The text is included in the executable, ensuring that users always have access to the version history regardless of their file system.

Version 1.0.2.3 (2026-07-04)
* Added StatusBar to the MainWindow to display the number of krabbels and changes need to be saved.

Version 1.0.1.2 (2026-07-03)
* Added a new property DisplayKeywords to the Krabbel class, which returns a comma-separated string of keywords for display purposes.
* Bug fix: Fixed an issue where the application would crash when adding a new keyword to a krabbel. The error occurred due to an unhandled exception when creating a new KeywordCard. Now, the application will handle the exception gracefully and allow the user to continue using the application without interruption.
* Added deletion of a open krabbel.
* Added prevention of losing krabbels.

Version 1.0.0.1 (2026-07-02)
* Initial version.
